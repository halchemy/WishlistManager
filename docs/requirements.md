# WishlistManager 要件定義書

## 1. プロジェクト概要

### 1.1 サービス概要
様々なショッピングサイトのほしいものを一元管理できるWebサービス。
ユーザーは複数のECサイトの商品をURLで登録し、統一されたインターフェースで管理できる。

### 1.2 サービス名（仮）
WishlistManager

### 1.3 ターゲットユーザー
- 複数のショッピングサイトを利用するユーザー
- ほしいものを整理・管理したいユーザー
- 計画的な買い物をしたいユーザー

## 2. 機能要件

### 2.1 機能一覧と優先度

| 優先度 | 機能カテゴリ | 機能名 | 説明 |
|:------:|-------------|--------|------|
| 高 | 認証 | ユーザー登録 | メールアドレス・パスワードでのアカウント作成 |
| 高 | 認証 | ログイン/ログアウト | 認証機能 |
| 高 | 商品管理 | 商品登録（URL） | URLを入力して商品を登録 |
| 高 | 商品管理 | 商品登録（手動） | 商品名・価格・画像などを手動入力 |
| 高 | 商品管理 | 商品一覧表示 | 登録した商品を一覧で確認 |
| 高 | 商品管理 | 商品編集 | 登録済み商品情報の編集 |
| 高 | 商品管理 | 商品削除 | 登録済み商品の削除 |
| 中 | 商品管理 | 購入済みマーク | 購入した商品にマークを付ける |
| 中 | 整理 | カテゴリ/タグ管理 | 商品をカテゴリやタグで分類 |
| 中 | 整理 | 並び替え・フィルター | 価格順、登録日順、カテゴリ別など |
| 中 | 整理 | 検索 | 登録商品の検索 |
| 中 | 拡張機能 | ブラウザ拡張機能 | ワンクリックで商品を登録 |
| 低 | ソーシャル | リスト共有 | 他ユーザーとほしいものリストを共有 |
| 低 | 通知 | 価格変動通知 | 価格変更時にメール等で通知（将来検討） |

### 2.2 主要機能の詳細

#### 2.2.1 ユーザー認証
- **登録**: メールアドレス + パスワード
- **ログイン**: メールアドレス + パスワード
- **パスワードリセット**: メールによるリセットリンク送信
- **セッション管理**: JWT or セッションベース認証

#### 2.2.2 商品登録（URL入力）
```
入力: URL
↓
処理: OGP情報（Open Graph Protocol）を取得
  - og:title → 商品名
  - og:image → 商品画像
  - og:description → 説明
  - og:site_name → サイト名
↓
出力: 取得情報をプレビュー表示、ユーザーが確認・編集後に保存
```

**設計方針**:
- 特定サイトのスクレイピングに依存しない
- OGP対応していないサイトは手動入力で対応
- 価格は自動取得せず、ユーザーが手動入力（サイト依存を避けるため）

#### 2.2.3 商品登録（手動入力）
| フィールド | 必須 | 説明 |
|-----------|:----:|------|
| 商品名 | ○ | 商品のタイトル |
| URL | - | 商品ページへのリンク |
| 価格 | - | 商品価格（通貨指定可能） |
| 画像 | - | 商品画像（URL or アップロード） |
| メモ | - | 自由記述 |
| カテゴリ | - | 分類用カテゴリ |
| タグ | - | 複数タグ付け可能 |
| 優先度 | - | 高/中/低 |

#### 2.2.4 ブラウザ拡張機能（Chrome Extension）
- 閲覧中のページで拡張機能アイコンをクリック
- OGP情報を自動取得してポップアップ表示
- 必要に応じて編集し、ボタン一つでWishlistManagerに登録
- ログイン状態の連携

#### 2.2.5 リスト共有（低優先度）
- 共有リンクの発行（URLで共有）
- 閲覧権限のみ / 編集権限の選択
- プレゼント用途: 購入済みマークを共有者に表示/非表示

## 3. 非機能要件

### 3.1 パフォーマンス
- ページ読み込み: 3秒以内
- 商品一覧: 100件程度まではスムーズに表示

### 3.2 セキュリティ
- HTTPS必須
- パスワードのハッシュ化保存
- CSRF対策
- XSS対策
- SQLインジェクション対策

### 3.3 可用性
- 個人サービスとして運用開始、成長に応じてスケール

### 3.4 対応環境
- **デバイス**: デスクトップのみ
- **ブラウザ**: Chrome, Firefox, Safari, Edge（最新版）
- **解像度**: 1280px以上を想定
